## 🚀 About This Project

This is my personal portfolio website — a premium, cinematic dark-themed application built with **Next.js**, **Framer Motion**, **Three.js**, and **TailwindCSS**. It showcases my work in AI/ML research, full-stack development, and technical product management.

### ✨ Key Features

- **🧬 Research Showcase** — Published paper with DOI, PDF download, and Zenodo integration
- **📊 11+ Project Cards** — Real GitHub repos with live demo links and source code
- **⚡ Animated Role Rotator** — Dynamic typing animation cycling through roles
- **🎨 3D Visualizations** — Interactive Three.js/R3F project previews
- **📱 Responsive Design** — Pixel-perfect on mobile, tablet, and desktop
- **🟢 Live Status** — "What I'm Working On" section with real-time activity
- **📝 Blog** — Technical articles on AI/ML and engineering
- **🧭 Professional Navbar** — Glass-morphism, active section tracking, mobile menu
- **✨ Cinematic Effects** — Custom cursor, particles, scroll progress, ambient glow

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Izumi6/website.git
cd website

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
